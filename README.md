# ReadmitIQ — 30-Day Hospital Readmission Risk System

A production-grade clinical AI system that predicts 30-day hospital 
readmission risk at the point of patient discharge using an XGBoost 
model trained on synthetic clinical data.

## Live Demo
- **Dashboard:** https://readmitiq.vercel.app *(coming soon)*
- **API docs:** https://drkryptomed-readmitiq-api.hf.space/docs *(coming soon)*

---

## Model Performance

| Metric | Value |
|--------|-------|
| AUC-ROC | **0.891** (exceeds 0.75 clinical benchmark) |
| Recall | **77%** — catches 4 in 5 readmissions |
| Fairness | IBM AIF360 audited — PASS for gender and age |
| Training data | Synthea 11,381 synthetic patients |
| Features | 31 clinical features (LACE index + comorbidities + medications) |

## Quick Start

### Option 1 — Docker (runs full stack)
```bash
docker-compose up --build
```
- Dashboard: http://localhost:3000
- API docs:  http://localhost:7860/docs

### Option 2 — Local development

**Terminal 1 — Backend:**
```bash
cd backend
conda activate readmission-env
uvicorn src.api.main:app --reload --port 7860
```

**Terminal 2 — Frontend:**
```bash
cd frontend
npm run dev
```
- Dashboard: http://localhost:3000
- API docs:  http://localhost:7860/docs

## Setup — Backend Environment

```bash
conda create -n readmission-env python=3.11
conda activate readmission-env
conda install numpy=1.26.4 setuptools -c conda-forge -y
pip install -r backend/requirements.txt
```

**Known issue:** On Windows, install `setuptools` via conda before pip to avoid `pkg_resources` errors.

## Clinical Disclaimer

This system is a **clinical decision support tool**. It does not replace 
clinical judgement. Predictions are generated by an XGBoost model (AUC 0.891) 
trained on synthetic data (Synthea). Not validated on real patient cohorts. 
Always corroborate with full clinical evaluation.
